<h2 id="task-1">
Task 1: All anagrams for a word
</h2>
Write a program which prints out all anagrams for a given word. For more information about Anagram, please check this [wikipedia](https://en.wikipedia.org/wiki/Anagram) page.

---
### Solution
Build a criterion for an anagram of the given word and apply it to the words of a dictionary.

#### Perl
Create a regular expression that:
- for each letter of the given word:
  - matches a word having exactly as many occurrences of that letter
- has the same length as the given word

Apply this to the dictionary with all words converted to lower case and all duplicates removed.

```perl
use strict;
use warnings;
use autodie;
use experimental 'signatures';
use List:MoreUtils 'frequency';
use List::Util 'uniqstr';

sub anagrams ($word, $dict) {
    my %freq = frequency split //, $word;
    my $re = '';
    $re .= "(?=(?:[^$_]*+[$_]){$freq{$_}}[^$_]*+\$)" for keys %freq;
    my $full = ".{" . length($word) . "}";
    open my $words, '<', $dict;
    my @anagrams;
    while (<$words>) {
        chomp;
        push @anagrams, lc if /^$re$full$/i;
    }
    close $words;
    uniqstr @anagrams;
}
```

<h2 id="task-2">
Task 2: Sequence with most anagrams
</h2>
Write a program to find the sequence of characters that has the most anagrams. ### Solution
Reduce the dictionary to unique lowercase word, sort the letters of each word, find the frequencies of these and pick the letters for the most frequent result.
#### Perl
```perl
use strict;
use warnings;
use autodie;
use experimental 'signatures';
use List::Util 'uniqstr';
use List::MoreUtils 'frequency';
use List::UtilsBy 'max_by';

sub most_anagrams ($dict) {
    open my $words, '<', $dict;
    my @all = <$words>;
    close $words;
    chomp @all;
    my @words = map join('', sort split //), uniqstr map lc, @all;
    my %words = frequency @words;
    max_by {$words{$_}} keys %words;
}
```
