<h2 id="task-1">
TASK #1 › Eban Numbers
</h2>
**Submitted by: [Mohammad S Anwar](http://www.manwar.org/)**

---
Write a script to generate all `Eban Numbers` <= 100.

> An Eban number is a number that has no letter ’e’ in it when the number is spelled in English (American or British).

#### Example
```
2, 4, 6, 30, 32 are the first 5 Eban numbers.
￼

```
---
### Solution
Convert numbers to strings using
[`Lingua::Any::Numbers`](https://metacpan.org/pod/Lingua::Any::Numbers)
and discard all that contain an `e`.
#### Perl
```perl
use strict;
use warnings;
use Lingua::Any::Numbers ':std2';

sub eban_numbers {
     grep to_string($_) !~ /e/, 0 .. shift;
}
```

<h2 id="task-2">
TASK #2 › Cardano Triplets
</h2>
**Submitted by: [Mohammad S Anwar](http://www.manwar.org/)**

---
Write a script to generate first `5 Cardano Triplets`.

> A triplet of positive integers (a,b,c) is called a Cardano Triplet if it satisfies the below condition.

$$
\sqrt[3]{a + b \sqrt{c}} + \sqrt[3]{a - b \sqrt{c}} = 1
$$

#### Example
```
(2,1,5) is the first Cardano Triplets.
```
---
### Solution
There is a minor issue with this task: Triplets have no underlying order and therefore the concept of "the first 5 triplets" is rather vague.

For the sake of convenience, ordering the triplets by the sum of their elements and lexicographically for identical sums.

Though Cardano triplets are defined as fulfilling the equation _exactly_, here we need to allow an approximate equality.

I didn't investigate a way to find Cardano Triplets better than scanning through _all_ triplets.

#### Perl
Need to define a helper function for the cubic root that handles negative arguments.
```perl
use strict;
use warnings;
use experimental 'signatures';
use Math::Prime::Util 'forcomp';

sub cubrt ($x) {
    abs($x) ** (1/3) * ($x < 0 ? -1 : 1);
}

sub card ($a, $b, $c) {
    cubrt($a + $b * sqrt($c)) + cubrt($a - $b * sqrt($c));
}

sub cardano_triplets ($cnt) {
    my @card;
    my $n = 3;
    while (@card < $cnt) {
        forcomp {
            push @card, [@_] if abs(card(@_) - 1) < 1e-8
        } $n++, {n => 3};
    }
    @card;
}
```

#### J
The code to generate _compositions_ was taken from the
[J Wiki](https://code.jsoftware.com/wiki/Essays/Compositions).

Again, cubic roots need to be treated especially: J's "root" primitive `%:` handles negative arguments, but returns the _principal value_ of the root, which is a complex number.
Applying the root to the absolute value and adjusting the sign to get the trivial result.

The comparison between numbers in J is tolerant by default.

It's the same logic as in the Perl solution:
- loop over sizes until the requested number of triplets has been found
- loop over compositions and find all Cardano Triplets of that size
