<h2 id="task-1">
Task 1: Compare Version
</h2>
Compare two given version number strings **v1** and **v2** such that:

- If **v1 > v2** return 1
- If **v1 < v2** return -1
- Otherwise, return 0

The version numbers are non-empty strings containing only digits, and the dot ("`.`") and underscore ("`_`") characters. ("`_`" denotes an alpha/development version, and has a lower precedence than a dot, “`.`”). Here are some examples:

```
v1   v2    Result
------ ------ ------
0.1 < 1.1     -1
2.0 > 1.2      1
1.2 < 1.2_5   -1
1.2.1 > 1.2_1    1
1.2.1 = 1.2.1    0
```
Version numbers may also contain leading zeros. You may handle these how you wish, as long as it’s consistent.

---
### Solution
Here we need a kind of lexicographical comparison, where a string compare comes close the requested result.
Splitting every version string into parts:
- several decimal numbers, separated by dots
- followed by any number of underscore / number pairs

Every number and every separator produces one part that is represented as.
- a packed sequence of bytes in big-endian order for a number
- a packed `-1` for a dot
- a packed `-2` for an underscore

With this encoding:
- two positive integers compare numerically the same as their packed representations as strings
- a dot is larger than every positive integer and as an underscore
- an underscore is larger than every positive integer but smaller than a dot.

The concatenation of all the parts from a version results in a (binary) string that can be compared to other version representations using a _binary string compare_.

```perl
use strict;
use warnings;
use experimental 'signatures';

sub compare_version ($v1, $v2) {
    state sub vstr ($v) {
        $v =~ m{^(?:\d++\.?+)++(?:_\d++)*+$} or die "version invalid: $v";
        pack "i>*",
            map /\./ ? -1 :
                /_/  ? -2 : $_,
            split /(\.|_)/, shift;
    }

    no locale;
    vstr($v1) cmp vstr($v2);
}
```

### Solution

Here is an extract from my solution dated 28 Jun 2020:

```perl
use strict;
use warnings;

use List::MoreUtils qw(pairwise firstidx reduce_1);

# exchange item at position $pos and next taller item.
# return position of found next item.
sub exchange {
	my ($items, $pos) = @_;
	my $pos_height = $items->[$pos]{height};
	my $next = $pos + firstidx {$_->{height} > $pos_height}
		@$items[$pos..$#$items];
	@$items[$pos, $next] = @$items[$next, $pos];
	return $next;
}

sub lineup {
	my ($heights, $talls) = @_;
	die "hights and talls have different sizes" if @$heights != @$talls;

	# collect hights and talls into single array.
	my @items = sort {$a->{height} <=> $b->{height}}
		pairwise { {height => $a, taller => $b} } @$heights, @$talls;

	# check solvability: the required number of taller predecessors must
	# not exceed the number of taller items.
	reduce_1 {$a && $b->{taller} <= $#items - $_} @items
			or die "no solution";

	# create an index to locate items in the array.
	my @index = (0 .. $#items);

	# process items by size.
	for (my $i = 0; $i < @index; $i++) {
		my $pos = $index[$i];
		my $item = $items[$pos];

		# move item to the right for the desired number of taller
		# predecessors.
		foreach my $offs (1 .. $item->{taller}) {
			# store new position of moved item
			$index[$i + $offs] = $pos;
			$pos = exchange \@items, $pos;
		}
	}
	return [map $_->{height}, @items];
}
```
