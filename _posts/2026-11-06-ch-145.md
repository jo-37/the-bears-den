TASK #1 › Dot Product
</h2>
**Submitted by: [Mohammad S Anwar](http://www.manwar.org/)**

---
You are given 2 arrays of same size, `@a` and `@b`.

Write a script to implement `Dot Product`.

Example:
```
@a = (1, 2, 3);
@b = (4, 5, 6);

$dot_product = (1 * 4) + (2 * 5) + (3 * 6) => 4 + 10 + 18 => 32
```
---
### Solution
This is my solution dated 30 Apr 2023:
```perl
use strict;
use warnings;
use PDL;

sub dot_product ($x, $y) {
    (pdl($x) x pdl($y)->dummy(0))->sclr;
}
```

### Solution
Sadly I was not able to use the information from the linked
[blog](https://medium.com/@alessiopiergiacomi/eertree-or-palindromic-tree-82453e75025b)
for an actual implementation. Therefore I searched for [other sources](#ref).
Though I was not satisfied with any of these neither, in _summary_ all these sources turned out to be sufficient.
Certainly I didn't want just to port any of the provided implementations to Perl.

In my first attempt I used [`Graph`](https://metacpan.org/pod/Graph) to build the Eertree.
Some try-and-error cycles led to a working solution, with two findings:
- A general graph is not the perfect model for an Eertree.
- A working application is very helpful for the understanding of the algorithm.

With these insights I started with a new version from scratch.

The basic design:
- An `Eertree::Edonode` class that represents the nodes of an `Eertree`.
- An `Eertree` class that provides
  - a constructor for an "empty" Eertree
  - a method to add one character to the tree and
  - a method to retrieve the identified sub-palindromes.

Starting with `Eertree::Edonode`, we need a constructor and some accessors.

Some details:
- an `undef`'ined palindrome has a length of `-1`
- for convenience the lengths are kept redundantly


```perl
package Eertree::Edonode;

sub new ($class, $palindrome) {
    bless {
        palindrome => $palindrome,
        length => defined($palindrome) ? length($palindrome) : -1,
        suffix => undef,
        transition => {},
    }, $class;
}

sub palindrome ($self) {
    $self->{palindrome};
}

sub length ($self) {
    $self->{length};
}


```
Getter and Setter for transition and suffix links:
```perl
sub transition ($self, $char, $dest=undef) {
    if (@_ == 2) {
        return $self->{transition}{$char};
    }
    $self->{transition}{$char} = $dest;
    $self;
}

sub suffix ($self, $dest=undef) {
    if (@_ == 1) {
        return $self->{suffix};
    }
    $self->{suffix} = $dest;
    $self;
}
```
Finally there is a method to extend a palindrome by one character.
The character is prepended to a defined palindrome and appended to any.
```perl
sub extend ($self, $c) {
    my $ex = $self->palindrome;
    $ex = $c . $ex if defined $ex;
    $ex .= $c;
    $ex;
}
```
Next comes the `Eertree` class with its constructor that initializes:
- the two root nodes (empty/even and undefined/odd)
- an empty source string
- the current node with the odd/undefined root
- an empty sequence array to track the identified sub-palindromes in their order

Note: The undefined/odd root _per definition_ represents a palindrome and a suffix of any string, while the even/empty root obviously _possesses_ these properties.

```perl
package Eertree;

sub new ($class) {
    my $empty = Eertree::Edonode->new('');
    my $undef = Eertree::Edonode->new(undef);
    $empty->suffix($undef);
    $undef->suffix($undef);
    bless {
        empty => $empty,
        undef => $undef,
        source => '',
        current => $undef,
        sequence => [],
    }, $class;
}
```
We need an internal helper method to determine the longest predecessor palindrome, that - when extended by the new character - is a suffix of the source string, starting the search at a given palindrome node.

There is a vital precondition for this method to produce a valid result:  
<span id="R">`R`</span>: The given node's palindrome must be a suffix of the source string without its trailing character.

As this is an internal method, it's the caller's responsibility that this precondition is fulfilled for the given starting node.
```perl
sub _longest_predecessor ($self, $node) {
    for (; $node; $node = $node->suffix) {
        my $pos = length($self->{source}) - $node->length - 2;
        last if $pos >= 0 &&
            substr($self->{source}, $pos, 1) eq substr($self->{source}, -1);
    }
    $node;
}
```
And now for the heart of the implementation:
Augment the Eertree by one character.

In the following, terms in _italics_ refer to a specific, fixed object within the described process.

- Append the _new character_ to the _source string_.
- Find the longest palindromic _predecessor_ for the _source string_, starting from the _current node_.  
  Note: The _current node_ was a suffix of the _source string_ before the _new character_ had been added and therefore fulfills the requirement [`R`](#R).
- If a transition from the _predecessor_ via the _new character_ already exists:
  - Use the transition target as the new _current node_ and **stop**.  
Note: The transition target is the longest palindromic suffix of the _source string_.

- Create a _new suffix_ by extending the _predecessor_ by the _new character_.
- Create a _new node_ for _the new suffix_.
- Record the _new node_ in the _sequence_.
- If the _new suffix_ is a single character:
  - Set its suffix link to the _even/empty root_.
- Otherwise:
  - Find the longest palindromic predecessor for the _source string_, starting with the suffix of the _predecessor_, transition to the child corresponding to the _new character_ and use this as the suffix link for the _new suffix_.
(For me, this was the hardest part to understand from the whole algorithm.)  
Note: The suffix of the _predecessor_ fulfills the requirement [`R`](#R), too.
- Set a transition from the _predecessor_ to the _new node_ via the _new character_.
- Select the _new node_ as the _new current_ node.  
Note: The _new node_ is the longest palindromic suffix of the _source string_.

```perl
sub add ($self, $c) {
    $self->{source} .= $c;
    my $predecessor = $self->_longest_predecessor($self->{current});
    my $pc = $predecessor->transition($c);
    return $self->{current} = $pc if $pc;

    my $palindrome = $predecessor->extend($c);
    my $new = Eertree::Edonode->new($palindrome);
    push $self->{sequence}->@*, $new;
    my $suffix = $new->length == 1 ?
        $self->{empty}
    :
        $self->_longest_predecessor($predecessor->suffix)->
            transition($c);
    $new->suffix($suffix);
    $predecessor->transition($c, $new);
    $self->{current} = $new;
}
```
Finally, a method to return all sub-palindromes in creation order:
```perl
sub palindromes ($self) {
    map $_->palindrome, $self->{sequence}->@*;
}
```
Wrapping these parts into a single function:
```perl
package main;

sub eertree ($s) {
    my $eertree = Eertree->new;
    $eertree->add($_) for split //, $s;
    $eertree->palindromes;
}
```
The order of the identified sub-palindromes is partially different from the examples:
```
$ perl/ch-2.pl rotors
r o t oto rotor s
```
