<h2 id="task-1">
TASK #1 › Truncatable Prime
</h2>
**Submitted by: [Mohammad S Anwar](http://www.manwar.org/)**

---
Write a script to generate first 20 left-truncatable prime numbers in base 10.

> In number theory, a left-truncatable prime is a prime number which, in a given base, contains no 0, and if the leading `left` digit is successively removed, then all resulting numbers are primes.

#### Example
```
9137 is one such left-truncatable prime since 9137, 137, 37 and 7 are all prime numbers.
```
---
### Solution
This is my solution dated 1 May 2023:
```perl
use strict;
use warnings;
use Math::Prime::Util qw(fromdigits todigits);

sub is_truncatable_prime ($p, $b) {
    my @p = todigits($p, $b);
    while (@p) {
        $p = fromdigits([@p], $b);
        return unless is_prime($p);
        shift @p;
    }
	1;
}
```

<h2 id="task-2">
TASK #2 › Pentagon Numbers
</h2>
**Submitted by: [Mohammad S Anwar](http://www.manwar.org/)**

---
Write a script to find the first pair of `Pentagon Numbers` whose sum and difference are also a Pentagon Number.

> Pentagon numbers can be defined as P(n) = n(3n - 1)/2.

#### Example
```
The first 10 Pentagon Numbers are:
1, 5, 12, 22, 35, 51, 70, 92, 117 and 145.

P(4) + P(7) = 22 + 70 = 92 = P(8)
but
P(4) - P(7) = |22 - 70| = 48 is not a Pentagon Number.
```
---
### Solution
The formula for a Pentagon number

$$
\operatorname{p}(n) = \frac{n(3n - 1)}{2}
$$

can easily be inverted as

$$
\operatorname{p}^{-1}(m) = \frac{\sqrt{24m + 1} + 1}{6}
$$

resulting in a real number.
To see if a number $$m$$ is a Pentagon number, we may check if the inverse of $$m$$ is an integer.

To find a pair of Pentagon numbers where both sum and difference are Pentagon numbers, we may process two nested loops where one (increasing) Pentagon number is checked against all smaller ones.

#### Perl

```perl
use strict;
use warnings;
use experimental 'signatures';

sub pentagon_pair {
    state sub pentagon ($k) {
        $k * (3 * $k - 1) / 2;
    }

    state sub is_pentagon ($n) {
        my $m = (sqrt(24 * $n + 1) + 1) / 6;
        $m == int $m;
    }

    my @seen;
    my $i;
    while () {
        my $pi = pentagon(++$i);
        is_pentagon($pi - $_) && is_pentagon($pi + $_) && return ($pi, $_)
            for @seen;
        push @seen, $pi;
    }
}
```
