Task 1: Largest Interval
</h2>
**Submitted by: [Ali Moradi](https://deadmarshal.blogspot.com/)**

---
You are given a positive integer.

Write a script that generates a sequence of integers from 1 to given positive integer, filtering out any numbers that contain repeating digits (e.g., 11, 99, 100, and 101 are excluded) and return the biggest jump.
### Example 1
```
Input: $int = 20
Output: 2

Biggest jump between 10 and 12.
```
### Example 2
```
Input: $int = 110
Output: 4

Biggest jump between 98 and 102.
```
### Example 3
```
Input: $int = 500
Output: 11

Biggest jump between:
a) 109 and 120 => 11
b) 219 and 230 => 11
c) 329 and 340 => 11
d) 439 and 450 => 11
```
### Example 4
```
Input: $int = 2026
Output: 105

Biggest jump between 1098 and 1203.
```
### Example 5
```
Input: $int = 10000
Output: 105

The largest gap is 105, between 1098 and 1203. And again between 8796 and 8901.
```
---
### Solution
The length of an interval is one more than the number of skipped numbers therein,
i.e any skipped number enlarges a possible interval by one.
As an interval (in this task) needs a number as its end that has not been skipped,
the size of an interval is not known before a following number is being kept.

Whenever an interval is closed, we find the corresponding length and we may take the maximum over all lengths.
At the same time we need to restart counting from zero.

It would be tedious to loop over all numbers from 1 to $$n$$.
The number of checks may be significantly reduced by the following considerations:
- If a number contains a duplicate digit, then all succeeding numbers will contain the same pair until the lower significant duplicate digit gets incremented. These increments may be integrated into one single step.
Consider "1234356": this number and the next 99 have the digit pair "xx3x3xx".
- An interval of maximum length must contain a number I'll call a _transition point_. At such a point a trailing series of nines turns into a trailing series of zeroes. There are always numbers containing duplicate digits before and after the _transition point_.
- There are only two kinds of transition points where a new maximum is achieved:
$$10^i$$ and $$11\cdot10^{i-1}$$ for any $$i$$.
  - The count of numbers with duplicate digits succeeding $$11 \cdot 10^{i-1}$$ is in the magnitude of $$10^{i-1}$$.
  - The count of numbers with duplicate digits preceding $$10^i$$ is in the magnitude of $$10^{i-2}$$ and similarly of $$2 \cdot 10^{i-2}$$ succeeding it. Together these are more than $$10^{i-2}$$ - the magnitude of the maximum interval length below $$10^{i-2}$$.

  Whenever we reach a number without duplicate digits, we may jump forward toward the next larger _transition point_, though there may be intervals having the same size in between.

- When a transition point has extra trailing zeroes (which is true for all of the above except 110),
then there are preceding numbers having duplicate digits. The starting number of such a series is produced by subtracting an offset built from a series of ascending digits, starting with $$1$$.
Examples: The transitions around $$100$$, $$1000$$, $$1100$$ and $$10000$$ start at
$$100 - 1 = 99$$, $$1000 - 12 = 988$$, $$1100 - 1 = 1099$$ and $$10000 - 123 = 9877$$.

- The process starts at $$i = 1$$, $$n = 11 \cdot 10^{1 - 1} = 11$$.

#### Perl

```perl
use strict;
use warnings;
use experimental qw(signatures vlb);
use POSIX 'Inf';

# integer decadic logarithm
sub ldi {
    length(shift) - 1;
}

# number of trailing zeroes
sub ntz {
    shift =~ /0*$/;
    $+[0] - $-[0];
}

# detect and process duplicate digits:
# - provide increment if duplicates
# - provide next value if unique
# force termination when $i exceeds the
# largest possible number having no duplicate digits
sub dupl ($i) {
    if ($i =~ /(.)(?<=(?=\1).{2,10})/) {
        return (1, 10**(ldi($i) - $-[1]))
    } else {
        my $transition = 11 * 10**(ldi($i) - 1);
        my $next = $i < $transition ?
            $transition : 10 ** (ldi($i) + 1);
        my $s = 0;
        $s = $s * 10 + $_ for 1 .. ntz($next) - 1;
        $next -= $s;
        $next = Inf if $next > 9876543210;
        return (0, $next);
    }
}

sub largest_interval ($n, $verbose=undef) {
    my ($i, $run, $max) = (11, 0, 0);
    while ($i <= $n) {
        my ($skip, $x) = dupl($i);
        if ($skip) {
            $run += $x;
            $i += $x;
        } else {
            $max = $run;
            printf "[%d, %d]: %d\n", $i - $run, $i - 1, $run if $verbose;
            $run = 0;
            $i = $x;
        }
    }
    $max + 1;
}
```

Task 2: Minimum Genetic Mutation
</h2>
**Submitted by: [Mohammad Sajid Anwar](https://manwar.org/)**

---
You are given start and end gene string along with gene bank.

Write a script to return the minimum number of mutations required to mutate from start to end gene. Return -1 if there is no such mutation. A gene must be in a bank to make it a valid gene string.

> A gene string can be represented by an 8-character long string, with choices from ‘A’, ‘C’, ‘G’, and ‘T’.

### Example 1
```
Input: $start_gene = "AACCGGTT"
       $end_gene   = "AACCGGTA"
       @gene_bank  = ("AACCGCTA", "AAACGGTA")
Output: -1

To reach end gene, every intermediate gene and the end gene itself must exist in bank.
Since "AACCGGTA" is missing from bank, it is impossible to complete the mutation sequence.
```
### Example 2
```
Input: $start_gene = "AACCGGTT"
       $end_gene   = "AACCGGAA"
       @gene_bank  = ("AACCGGTA", "AACCGGAA", "AACCGCTA", "AACCCTAA", "AACCGTAA")
Output: 2

Path 1 (2 steps): "AACCGGTT" => "AACCGGTA" => "AACCGGAA"
Path 2 (3 steps): "AACCGGTT" => "AACCGGTA" => "AACCGTAA" => "AACCGGAA"
```
### Example 3
```
Input: $start_gene = "AAAAAAAA"
       $end_gene   = "AAAAACCC"
       @gene_bank  = ("CAAAAAAA", "CCAAAAAA", "AAAAAAAC")
Output: -1
```
### Example 4
```
Input: $start_gene = "GAAAAAAA"
       $end_gene   = "GCCCCCCC"
       @gene_bank  = ("GCAAAAAA", "GCCAAAAA", "GCCCAAAA", "GCCCCAAA", "GCCCCCAA", "GCCCCCCA", "GCCCCCCC")
Output: 7

"GAAAAAAA" => "GCAAAAAA"
"GCAAAAAA" => "GCCAAAAA"
"GCCAAAAA" => "GCCCAAAA"
"GCCCAAAA" => "GCCCCAAA"

```


### Solution
The genes may be regarded as vertices of an undirected graph, where two vertices are connected with an edge if the corresponding genes differ in exactly one nucleobase.

We add corresponding edges between all of the start gene and the genes from the bank.
In the resulting graph we search for the shortest path between the start and end genes.

#### Perl
Using the `Graph` package to represent the graph and to find the shortest path.
The path length that is requested in this task corresponds to the number of edges in the path, but `SP_Dijkstra` provides the path's edges.
Therefore the size of the paths needs to be decremented for the correct result.
When there is no path between the vertices, the function returns an empty list.
Decrementing this size leads to the expected value of `-1`.

To find the difference between two gene strings, these may be "string xor'ed" (`^.`) and unpacked as unsigned chars.
Every non-zero value signals a single difference.
```perl
use strict;
use warnings;
use experimental 'signatures';
use feature 'bitwise';
use Graph::Undirected;

sub mgm ($start, $end, $b) {
    my @b = ($start, @$b);
    my $g = Graph::Undirected->new(vertices => [$end, @$b]);
    while (my $x = shift @b) {
        1 == grep $_, unpack 'c*', $x ^. $_ and $g->add_edge($x, $_) for @b;
    }

    @{[$g->SP_Dijkstra($start, $end)]} - 1;
}
```

#### J
Using an implementation of the Floyd-Warshall APSP algorithm from the 
[J Wiki](https://code.jsoftware.com/wiki/Essays/Floyd).
This algorithm is not the best choice for this task, but was the easiest to be used I found in the Wiki.

To identify differences between gene strings these may simply be compared for "not equal".

If the start and end gene both correspond to vertices in the graph but there is no path connecting them, the Floyd-Warshall algorithm will return "infinity".
Analogously, we set the distance to "infinity" if the end gene has no corresponding vertex.
As the final step, infinity is transformed to minus one, covering both cases.

```j

  NB.   divergent nucleobases for zero or one disagreements.
  NB. - infinity otherwise

  NB. using the Floyd-Warshall algorithm.
  NB. See https://code.jsoftware.com/wiki/Essays/Floyd

  NB. from the distance matrix:
  NB. Find the index "ei" of "end" within "(start, db)" and
  NB. select element "(0, ei)".
  NB. Provide infinity on out-of-bound access.
  dist_se =. ] ({::~ :: _) 0 , }:@[ i. {:@[

  inf2neg =. (_1:)^:(_&=)

  NB. - Apply Floyd-Warshall to find the shortest paths.
  NB. - Find the distance between start and end gene.
  NB. - Handle infinity.
  [: : ([: ([: inf2neg ] dist_se [: floyd [: dist }:) start , db , end) f.
)
```
